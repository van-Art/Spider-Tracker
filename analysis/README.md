## Evidence levels

- **Observed**: reproduced in a live browser; screenshots and captured DOM/AX are retained.
- **Source-confirmed**: explicit in downloaded public HTML, CSS, JavaScript, or runtime JSON, but not necessarily activated in a capture.
- **Derived**: geometry calculated from CSS or a proposed translation into Android. These are labeled and are not additional website features.
- **Unknown**: cannot be established from the capture. Unknown does not mean absent.

## Main findings

The experience is a custom pixel-art instrument panel around a Google vector map. A fifteen-slice frame, animated head/menu, centered tracker badge, paired left filters, bottom ticker, sound control, lower-left character, radar, and footer create the persistent shell. Generic Material widgets would materially change the design.

There are two visible category filters, not a layer picker. Confirmed and rumored filters affect both markers and the activity log. Events and the trailer remain separately visible. The radar is an animated Canvas overlay with global and neighborhood actions. Neighborhood centering currently uses an IP-derived location cache; Android GPS is a deliberate requested substitution.

The page is generated by Astro with scoped CSS and browser ES modules. Modules communicate through document CustomEvents and a small global state controller. No full-page route changes were needed for the observed primary views.

Phone behavior is distinct: narrower frame slices and icons, a full map-area menu, smaller markers, an activity list without badges, and **vertical Web Watch articles instead of desktop carousel controls**. The two right-hand feeds overlay the whole viewport rather than staying inside the frame.

Brand logos, character sprites, media, and the commercial pixel font are references only. The independent app must use original artwork and independently licensed text/fonts/media, preserving their layout envelopes. The source site's imagery and Google map tiles must not become the Android basemap or app assets.
