Spider Tracker · Phase 2 independent native reconstruction

This application contains original scanner/mascot/marker/frame graphics and
original mock observations. It is not affiliated with the reference website,
Sony Pictures, Marvel or Samsung. No reference-site artwork is packaged.

GPS, routing, backend reporting, remote sightings, push and production video
services are not implemented in Phase 2. The target control centers a fixed
demo neighborhood; it does not read the user's location.
